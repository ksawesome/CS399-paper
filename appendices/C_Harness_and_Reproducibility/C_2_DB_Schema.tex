\subsection{SQLite Persistence Schema}\label{app:sqlite_schema}

The harness also persists outputs to a normalized SQLite database to enable efficient queries and reproducible analyses (\cref{subsubsec:data_persistence}). The core tables are:

\paragraph{runs} (\texttt{run\_id} PRIMARY KEY)
\begin{itemize}
\item \texttt{run\_id} (TEXT), \texttt{date\_time} (TEXT, ISO-8601), \texttt{seed} (INTEGER)
\item \texttt{price\_table} (JSON TEXT): snapshot of per-1k token prices used for \cref{eq:per_call_cost}
\item \texttt{config} (JSON TEXT): serialized configuration (models, concurrency, cooldowns)
\end{itemize}

\paragraph{prompts} (\texttt{prompt\_id} PRIMARY KEY)
\begin{itemize}
\item \texttt{prompt\_id} (TEXT), \texttt{prompt\_category} (TEXT)
\item \texttt{system\_prompt} (TEXT), \texttt{user\_prompt} (TEXT): exact issued prompts (post-templating)
\end{itemize}

\paragraph{responses} (composite key: \texttt{run\_id}, \texttt{prompt\_id}, \texttt{model})
\begin{itemize}
\item Foreign keys: \texttt{run\_id} \textrightarrow{} runs, \texttt{prompt\_id} \textrightarrow{} prompts
\item Identifiers: \texttt{model} (TEXT), \texttt{model\_version} (TEXT)
\item Telemetry: \texttt{latency\_ms} (REAL), \texttt{tokens\_in} (INTEGER), \texttt{tokens\_out} (INTEGER), \texttt{response\_length} (INTEGER)
\item Economics: \texttt{cost\_usd} (REAL)
\item Reliability: \texttt{http\_status} (INTEGER), \texttt{error\_code} (TEXT), \texttt{error\_message} (TEXT)
\item Text: \texttt{response\_text} (TEXT; subject to sanitization per \cref{subsec:sanitization_procedures})
\end{itemize}

Indexes on (\texttt{model}), (\texttt{prompt\_category}), and (\texttt{http\_status}) speed common queries used in \cref{sec:results,sec:statistical_analysis,sec:cost_modelling}. The schema ensures traceability from raw prompts to model responses and onward to human ratings (\cref{subsec:data_sources}).
