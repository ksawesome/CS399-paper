\section{Statistical Analysis}\label{sec:statistical_analysis}

We analyzed outcomes generated by the benchmarking harness and human scoring pipeline described in \cref{sec:benchmark_harness,sec:scoring_rubrics}. Because each model was evaluated on the same set of prompts (stratified by category; \cref{subsec:datasets_prompt_bank}), our design is a repeated-measures, matched comparison at the prompt level. All analyses honor this pairing and operate on the adjudicated/averaged human scores defined in \cref{subsec:socratic_quality_rubric,subsec:context_fidelity_rubric} together with the automated metrics recorded at ingestion (\cref{subsubsec:data_persistence,subsec:automated_metrics}). Unless noted, comparisons are conducted per prompt and then aggregated per model.

\subsection{Inter-Rater Reliability}\label{subsec:inter_rater_reliability}

Before aggregating human scores, we quantified agreement between independent raters. For ordinal rubric dimensions (Socratic quality and fidelity levels), we computed weighted Cohen's $\kappa$ with quadratic weights per dimension, alongside the two-way random-effects intraclass correlation coefficient ICC(2,$k$) on averaged scores. We report 95\% confidence intervals via nonparametric bootstrap resampling of items (stratified by prompt category) and percent agreement for completeness. Rater training, blinding, and adjudication procedures are described in \cref{subsec:sampling_blinding,subsubsec:evaluation_protocol}. 

Inter-rater reliability, as measured by quadratic weighted Cohen's $\kappa$, showed moderate agreement (Socratic: $\kappa=0.469$; Context: $\kappa=0.498$). However, the intraclass correlation coefficient (ICC), which is well-suited for averaged rater scores, met our preregistered threshold (ICC(2,$k$)=0.73 and 0.75, respectively), indicating sufficient reliability for aggregating scores and proceeding with the analysis. Percent agreement was 52\% and 56.5\%, respectively. Bootstrap intervals for these figures, together with the prompt-level calibration checks, are provided in \verb|data/statistical_analysis_details.json|. We adopted ICC as our primary reliability criterion because it directly assesses the consistency of averaged scores used in downstream analyses, whereas $\kappa$ evaluates exact rater-by-rater agreement on individual ordinal categories. The moderate $\kappa$ values reflect genuine variability in subjective pedagogical judgments across the 5-point rubric scale, but the strong ICC values confirm that this variability averages out appropriately when scores are aggregated per prompt, as required by our repeated-measures design.

\subsection{Comparative Analysis of Model Performance}\label{subsec:comparative_analysis}

Our primary endpoints are (i) the mean Socratic rubric score $Q$ (1--5; \cref{subsec:socratic_quality_rubric}) and (ii) the context score $S_{\text{context}}$ defined in \cref{eq:context_score}. Secondary endpoints include the binary components of context fidelity (inclusion and no-hallucination; \cref{subsec:context_fidelity_rubric}), automated proxies (\cref{subsec:automated_metrics}), and operational metrics (latency, cost; \cref{subsec:harness_implementation,subsubsec:core_functionality}).

Because all models answered the same prompts, we used nonparametric tests for repeated measures.

\begin{itemize}
	\item \textbf{Global $k$-model tests (ordinal/continuous endpoints):} For $Q$ and $S_{\text{context}}$, we applied the Friedman test across models with prompts as blocks. This assesses whether at least one model differs in central tendency without assuming normality.
	\item \textbf{Post-hoc pairwise tests (ordinal/continuous endpoints):} Where Friedman was significant, we ran paired Wilcoxon signed-rank tests for each model pair on per-prompt scores. P-values were adjusted using the Benjamini--Hochberg procedure within the family of comparisons for each endpoint. We report adjusted $p$-values ($q$-values) with a significance threshold $q<0.05$.
	\item \textbf{Binary endpoints:} For context inclusion and no-hallucination rates, we used Cochran's Q test for a global difference across models, followed by McNemar's exact tests for pairwise comparisons on discordant prompt counts, with Benjamini--Hochberg adjustment.
	\item \textbf{Latency and cost:} For latency (median and 95th percentile) and cost per interaction, distributions were right-skewed. We compared models using paired Wilcoxon tests on per-prompt values and report robust location differences via Hodges--Lehmann estimators (median of paired differences). Confidence intervals are obtained by bootstrap (\cref{subsec:confidence_intervals}).
\end{itemize}

All paired analyses include only prompts with valid responses for both models being compared. We additionally report an intention-to-treat sensitivity where failed calls are retained and coded as zero for quality and as missing for latency/cost; the latter are compared using available-case analyses but are summarized with failure rates to provide context (\cref{subsec:reliability_availability}).

The Friedman tests yielded $\chi^2(4)=120.07$ ($p=5.2\times10^{-25}$, Kendall's $W=0.25$) for pedagogical quality and $\chi^2(4)=101.98$ ($p=3.7\times10^{-21}$, $W=0.21$) for context fidelity, confirming systematic performance differences across the five models. Benjamini--Hochberg corrected Wilcoxon contrasts (\cref{fig:effect_size_heatmap}) show Gemini 2.5 Flash leading the pack: it exceeds Command R by a Hodges--Lehmann gain of +0.10 (rank-biserial $r_{rb}=0.53$, $q=1.1\times10^{-6}$), GPT-4o mini by +0.045 ($r_{rb}=0.26$, $q=0.015$), and Llama 4 Maverick by +0.26 ($r_{rb}=0.87$, $q=7.6\times10^{-16}$). The gap versus Claude 3 Sonnet is small and non-significant ($q=0.32$).

Context fidelity mirrors this pattern. Gemini 2.5 Flash and Claude 3 Sonnet outperform Command R (median gains +0.07 and +0.10, $q<10^{-5}$) and Llama 4 Maverick (+0.19 and +0.18, $q<10^{-12}$). Their head-to-head contrast is negligible ($+0.008$, $q=0.33$). GPT-4o mini trails Claude by 0.08 ($q=7.6\times10^{-4}$) while edging Command R by 0.04 ($q=0.054$). Detailed pairwise statistics, including Cliff's $\delta$ and $q$-values, are serialized in \verb|data/pedagogical_pairwise.csv| and \verb|data/context_pairwise.csv|.

\subsection{Effect Size}\label{subsec:effect_size}

For paired Wilcoxon tests we report the rank-biserial correlation ($r_{rb}$) and Cliff's $\delta$ as nonparametric effect sizes, together with the Hodges--Lehmann estimator of the median paired difference for interpretability. For Friedman tests we report Kendall's $W$ as a measure of concordance across models. For binary endpoints, we present risk differences and odds ratios with exact 95\% confidence intervals based on the paired counts (discordant cells). For latency and cost, we accompany $p$-values with Hodges--Lehmann differences and bootstrap intervals. The heatmap in \cref{fig:effect_size_heatmap} visualizes these contrasts, enabling a quick scan of the magnitude and direction of practical differences alongside their statistical support.

\subsection{Confidence Intervals for Performance Metrics}\label{subsec:confidence_intervals}

We used resampling to quantify uncertainty for skewed or bounded metrics. Specifically, we computed 95\% confidence intervals for $Q$, $S_{\text{context}}$, and operational metrics by stratified bootstrap over prompts (strata = prompt category; \cref{subsec:datasets_prompt_bank}), drawing 10{,}000 resamples with replacement. For quantiles (median, 95th percentile) we used the Harrell--Davis quantile estimator within each resample and reported percentile intervals. For paired differences we bootstrapped the set of paired prompt-level differences. Uncertainty for the overall model score $S_{\text{overall}}$ (\cref{eq:overall_score}) was obtained by recomputing \cref{eq:overall_score} in each bootstrap replicate after re-deriving $Q$ and $S_{\text{context}}$.

\paragraph{Multiple comparisons.} We controlled the false discovery rate using Benjamini--Hochberg within each endpoint family (human rubrics, binary fidelity, operational metrics). As a robustness check, we verified conclusions under Holm's step-down procedure.

\subsection{Regression Analysis}\label{subsec:regression_analysis}

To complement rank-based tests and exploit the full matched structure, we fit mixed-effects models with prompt-level random intercepts. These models allow adjustment for covariates (e.g., prompt category or system prompt variant; \cref{subsubsec:execution_modes}) and provide model-based marginal effects.

\begin{itemize}
	\item \textbf{Ordinal outcomes:} For individual rubric dimensions we fit cumulative link mixed models (proportional-odds) with fixed effect for model and random intercepts for prompt and rater. We summarize contrasts between models as odds ratios with 95\% CIs, adjusting $p$-values for multiple contrasts.
	\item \textbf{Continuous/positive outcomes:} For latency and cost we modeled $\log(\text{latency})$ and $\log(1+\text{cost})$ using linear mixed-effects with random intercepts for prompt. Estimated marginal means and pairwise contrasts were derived on the log scale and back-transformed.
	\item \textbf{Binary outcomes:} For inclusion and no-hallucination we fit logistic mixed-effects models with prompt random intercepts and report odds ratios for model contrasts.
\end{itemize}

All models use robust (clustered-by-prompt) standard errors. Results from mixed models were consistent with the nonparametric paired analyses and are provided in \cref{sec:results} as supplementary validation. Model diagnostics and sensitivity checks (alternative link functions, removal of high-influence prompts) did not materially change conclusions.

\paragraph{Handling missing data and exclusions.} Exclusions and error handling follow \cref{subsubsec:core_functionality,subsubsec:data_collection}. For paired tests, we restricted to complete prompt pairs. For mixed models, missingness on outcomes led to listwise deletion; failure rates are reported separately (\cref{subsec:reliability_availability}). Sensitivity analyses considered (i) winsorizing latency at the 99th percentile and (ii) imputing failed responses as the worst rubric scores; qualitative conclusions were unchanged.

\subsection{Empirical Results Summary}\label{subsec:statistical_results}

Executing the procedures above on the 120 matched prompts yields statistically robust separation across models:

\begin{itemize}
	\item \textbf{Pedagogical quality.} The Friedman result ($\chi^2(4)=120.07$, $p=5.2\times10^{-25}$, $W=0.25$) confirms a clear ordering. Gemini 2.5 Flash dominates Command R (median gain +0.10, $q=1.1\times10^{-6}$), GPT-4o mini (+0.045, $q=0.015$), and Llama 4 Maverick (+0.26, $q=7.6\times10^{-16}$). Claude 3 Sonnet sits between the top tier and the lower performers; its gap to Gemini is not statistically distinguishable ($q=0.32$).
	\item \textbf{Context fidelity.} Differences are similarly pronounced ($\chi^2(4)=101.98$, $p=3.7\times10^{-21}$, $W=0.21$). Gemini 2.5 Flash and Claude 3 Sonnet tie for the lead, each beating Command R by roughly +0.07 to +0.10 points ($q<10^{-5}$) and overrunning Llama 4 Maverick by +0.18 to +0.19 ($q<10^{-12}$). GPT-4o mini trails Claude by 0.08 ($q=7.6\times10^{-4}$) while maintaining a slim 0.04 advantage over Command R ($q=0.054$).
	\item \textbf{Context inclusion.} Cochran's $Q=14.98$ ($p=4.7\times10^{-3}$) reveals heterogeneous inclusion rates. McNemar contrasts (\cref{fig:context_inclusion_diff}) show Command R leading the cohort, with a +11.7 percentage point advantage over Llama 4 Maverick ($q=0.036$) and a +10.8 point edge over Claude 3 Sonnet ($q=0.036$).
	\item \textbf{Latency.} Paired Hodges--Lehmann differences (\cref{fig:latency_forest}) indicate Gemini 2.5 Flash is the fastest model, running 56 ms quicker than GPT-4o mini and 181 ms quicker than Llama 4 Maverick (all $q<5\times10^{-21}$).
	\item \textbf{Reliability.} Weighted Cohen's $\kappa$ of 0.469 (Socratic) and 0.498 (Context), with ICC(2,$k$) of 0.73 and 0.75 respectively, meet the preregistered acceptance thresholds, supporting aggregation of rubric scores.
\end{itemize}
